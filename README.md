This repository is where I document my journey through LeetCode problems as I build and sharpen my problem-solving skills. My goal isn't just to solve problems — it's to genuinely *understand* the logic and patterns behind them, one step at a time.

I'm learning, and I'm doing my best to reason through each problem deeply rather than just finding a solution that works. Hopefully this repo is useful to anyone else on a similar journey!

## 📁 Structure

This repo is organized by **pattern**, with each folder dedicated to a specific technique:

- `two-pointers/` → problems solved using the 2-pointer technique
- *(more pattern folders coming as I go — binary search, sliding window, etc.)*

## 👉 2 Pointers

You're currently looking at the **2-pointer** folder. This pattern is used for problems involving arrays or strings where you can use two indices moving toward each other (or in the same direction) to avoid nested loops and reduce time complexity.

Each solution here includes:
- The problem approach/logic
- Code implementation
- Notes on time & space complexity (where relevant)

I wanted a place to track my growth, revisit problems when I need a refresher, and build genuine intuition for common patterns — not just memorize solutions.
